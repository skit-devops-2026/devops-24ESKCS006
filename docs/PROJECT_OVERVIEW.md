# BreadBasket Project Overview

## Purpose

BreadBasket is a food donation platform designed to connect food donors with NGOs and help reduce edible food waste.

## Main Users

- Food Donors
- NGOs
- Volunteers

## Main Features

- Donor interface for food donations
- NGO dashboard
- Food category organization
- Impact information
- Login and registration pages

## Food Categories

- Cooked Food
- Bakery
- Fruits
